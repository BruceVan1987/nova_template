# 关键角色立场推演

写章或改稿启用角色推演时读取。执行边界统一以 [chapter-writing 的“章节正文严格串行”](../SKILL.md#0-章节正文严格串行)为准。

## 分别准备限知输入

每个只读 subagent 带入一名本场关键角色。主执行者分别提供共同场景前提、该角色档案、目标章关系卡，以及他此刻确实知道或误信的信息；已有可用的声口锚句时，定向附上作者认可的原文，不要求角色代理通读旧章。不把其他人的秘密或全知状态交给它再要求“假装不知道”，也不把“让他交出某信息”等预定结果当作推演任务。

角色只根据已确认的知情、利益、关系、当下目标和底线，独立推理对话意图、动作、试探、反制、冲突升级与退让条件。不同角色不彼此协商成同一个剧情答案。

表达方式以作者设定和已认可正文的稳定表现为先，结合已有教育背景、职业经历、性格、交谈对象与现场压力，按唯一规范的[对话与人物关系](../../../../references/style-guide.md#2-对话与人物关系)推演。缺少明确习惯时可暂拟本场表达选择，不凭职业补造教育程度、识字能力或身世；复现人物沿用已有表现，不每章重新随机设计。

## 返回材料

每个角色只返回一张立场推演卡：

`确知／误信 → 当下要保住什么 → 会先做什么 → 被逼急时可能升级到哪一步 → 如何回应其他人 → 要到什么地步才退 → 依据的事实源`

升级与退让按人物已定目标、性格和当前处境推导，不为方便既定路径强行改变立场。可给少量候选反应或台词意图，不编造新事实，也不修改任何项目文件；正文限制依主技能执行。

同一张卡附两三条本场最有用的表达倾向：先在意什么、什么话题会多说、被质疑时怎样回应，或交谈对象与刺激怎样改变其说法。选有依据的重点，不逐项填满；每条标清已有依据或本场暂拟，用行为倾向说明，不只贴性格标签。只返回表达意图，不生成完整对白、候选段落或可拼接正文。

## 主执行者收拢

全部推演返回后，用人物档案和当前知情边界剔除越界推断，保留各方真正不能相容的目标，再锁定控制卡。不同角色的结论允许冲突，不用投票或平均意见消解冲突；若有效立场否定暂拟路径，应换路径，而不是只取有利片段为原计划补借口。变更已锁定方向仍须作者决定。

收拢时同时保留人物选择和表达方式，不只摘取情节结果。从各卡选出本场最重要的表达差异，用简短完整的白话融入现有控制卡的「场面简报」；不新增必填栏目，也不把整张推演卡送给写手。本场暂拟习惯只约束此次尝试，不自动写成人物档案中的永久设定。
