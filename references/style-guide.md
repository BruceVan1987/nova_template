# 写作质量规范

本文件是正文质量的唯一规范。题材、人称、时态、基调和作品专属边界以 [`story.md`](../story.md) 为准；故事初始化后可按作者要求修改本文件，但不要从旧项目移植专属规则。

## 1. 基本声口

- 叙述语域、句子密度和幽默或严肃程度服从 `story.md`，不默认任何题材腔。
- 优先写人物能看见、听见、触到并作出反应的事实；抽象解释只保留会改变选择的部分。
- 需要现代网文大白话、古典语感、方言或其他特殊声口时，先由作者在故事合同与人物档案中确认。
- 故事合同若确认“古代背景、现代白话网文”，旁白和人物内心就用现代标准汉语句法；不倒装，不靠省略主语、宾语或关键动作营造古意。
- 历史感来自称谓、器物、职业、制度、礼法和人物的处境，不来自旁白仿古。不因为时代在古代，就把“没回答”改成“未应”，或把正常语序改成文言翻译腔。
- 诏书、律令、契约、军府文书等文本可以使用符合身份的正式或半文言语域；引用结束后，旁白仍用白话写清它给人物带来的实际后果。
- 句长跟随人物的注意和动作变化。短句可以在窒息、追逐或决断时短暂加速，但不能连续用同一节拍切碎正常叙事；空间、因果和反应应用完整句承载。
- 省略号只表示真正的迟疑、欲言又止或声音消失；突然中断用破折号，普通停顿用句号、动作或对方的反应。不用“……”代替每一处节奏。
- 已确认正文可用 `context --voice-chapter N` 作为限长声口样本；样章只约束 HOW，不提供目标章事实。

执行时按下列方向改写，不把例句当作可重复套用的模板：

- 坏例：“他未应，只将药囊置于案上。” → 好例：“他没回答，把药囊放到桌上。”
- 坏例：“少顷，遂命人将其带下。” → 好例：“过了一会儿，队正叫人把那名俘虏带走。”
- 坏例：“张成看向赵启。没答，便让带下去。” → 好例：“赵启没有回答。张成便叫守卫把他带了下去。”
- 坏例：“他获得消息，风险上升，两人关系缓和。” → 好例：“他从账页上认出了失踪者的名字。门外随即响起脚步声，同伴却把后门钥匙塞进了他手里。”
- 坏例：“文书称‘逾期不至，罪及保人’。他闻之，遂知事急。” → 好例：“文书上写着‘逾期不至，罪及保人’。他看懂了：自己今晚若不回去，作保的人也会被抓。”

### 可配置的声口检查

`novel-project.json` 的 `lint.light_register.enabled` 默认关闭。作者选择现代口语后可启用预设的轻度书面词检查，也可通过 `pattern` 自定正则、通过 `warn_per_k` 和 `block_per_k` 设定每千字提醒与交付阈值。引文和固定声口可由语言轮引用原句并记录 `retained` 理由；标题不计入该门槛。此检查只发现可机械匹配的词，不证明语言自然。

`lint.bare_dialogue.enabled` 同样默认关闭；启用后提醒连续四段纯对白，是否修改仍按现场语境判断。

### 落笔前自检

按作者已确定的语域写完整、自然的句子；事实表与控制卡提供事实，不提供正文措辞。用当前场景里的信息、动作和后果展开，不把计划完成情况写成正文总结。样本只参考表达方式，其中人物和剧情不是本章事实。

## 2. 对话与人物关系

- 每个人说话都受身份、欲望、关系阶段、实际知情和现场压力约束，不能只替作者传递信息。
- 熟人要能接住对方的话、动作和旧事；生人则保留试探、礼貌或误差。关系温度以 `continuity/relationships.md` 的目标章节阶段为准。
- 长对话必须有可辨的说话人、动作主体和现实目的；删掉姓名后所有台词都能互换，说明人物声口尚未成立。
- 多人场景里，说话人或动作主体一旦切换，就用姓名、称谓或明确身份重新锚定；不用连续的“他”、无主句或省略宾语让读者回头猜。
- 一轮对话里，每个人都在做自己的事：探口风、隐瞒、讨价、求助、拒绝或维持体面。不用一问一答把设定拆给两个人轮流念，也不让对方无条件接受方便作者的答案。
- 冲突通过具体选择、拒绝、交换和后果推进，不靠所有人轮流陈述立场。

### 人物的场内行为线

- 人物不只在开口时存在。承担本场选择或情绪转折的角色进入场景后，要有可持续追踪的身体状态、注意焦点和行为策略；三者共同构成一条随新刺激推进的在场状态，不在每轮对白后重新归零。
- 前一拍造成的伤痛、疲惫、呼吸、姿势、位置、手中物件、戒心和未消化情绪要带入后一拍。动作要承接或显露前因；关键动作还应改变之后的距离、风险、关系、判断或策略。删去后若人物状态、读者理解和后续场面都不变，或者换给谁都成立，通常只是装饰。
- 注意力体现人物。身份、经验、欲望和恐惧决定他先看见、漏掉或避开什么，并由此影响判断和下一步；不让所有人同时注意一组只为方便剧情而存在的细节。
- 情绪释放服从处境，不求刺激发生时立即说尽。危险、职责、体面和手头事务可以暂时压住反应，待压力改变后，再由身体、说话方式或选择显出。静止、沉默、装作无事和迟迟不动也可以构成行为。
- 配角只要参与关键选择，也要有自己想保住或害怕失去的东西。新信息会迫使他迟疑、遮掩、改口、误判或更换策略；不得只作为主角的赞同者、反对者或信息按钮。
- 不以动作数量衡量人物是否鲜活，也不要求每个在场者都有完整曲线。安静场面可以少动，追逐搏杀可以连续写身体变化；只要求承担选择或情绪转折者的状态不断裂。

例如，不要只写“‘我不怕。’他说得很坚定”。可以写成：“‘我不怕。’他把门闩插了两次才插进槽里，却没有让开门口。”手上的失误让害怕可见，仍然挡在门口才是人物的选择；下一拍若有人逼近，门闩、站位和他的害怕仍要继续影响行动，不能说完便消失。

## 3. 限知、受众与场内连续性

- 只写当前视角能够知道或合理推断的内容；不可用全知旁白替人物补答案。
- 台词、信件、题字、记录和公开动作都要按实际听众或读者核验。对方听不懂，不等于秘密没有输出。
- 人物进出场，以及上一拍造成的站位、伤情、疲劳、衣物、手中物件和声音来源要连续；视角切换必须清楚。
- 私密想法、双方私谈和公开场合使用不同的信息边界，不能只靠作者心里知道来区分。

## 4. 事实、数量与可执行性

- 人物能力、位置、物品持有、时间、方位和知情范围以结构化事实源为准。
- 钱、物资、人数、距离、日期和持续时间必须守恒；制作、运输、恢复、训练和消息传播需要成本与时间。
- 真实历史、科学、行业或制度细节在影响因果时核对可靠来源；不确定处保留不确定性。
- 设定边界应通过错误、代价、限制和选择自然生效，不让旁白反复念规则。

## 5. 叙事发动机与节奏

- 每章至少具备：人物的具体愿望、阻力、当场选择，以及选择造成的可见变化。
- 场景必须改变事实、关系、风险、资源或理解；只有程序说明和既知结果复核的内容，优先合并或压成消息。
- 控制卡、章纲和状态文件只提供因果，不提供正文措辞。“获得信息、风险上升、关系变化、完成转移”等工作台缩写进入正文前，必须还原为谁做了什么、谁看见了什么，以及当场发生的可见后果。
- 章末完成本章变化，不机械制造危机，也不隐瞒视角人物已经知道的事实。
- 连续章节若入口、主场动作和冲突结构同构，应回到 arc 层调整，而不是靠换名词维持篇幅。

## 6. 高频 AI 痕迹

下列写法不是见一次就机械删除，但连续出现或承担关键情绪时，必须改成具体动作、事实与选择：

- “眼中闪过一丝……”“嘴角勾起一抹……”“空气仿佛凝固”等套语。
- “不是……而是……更是……”式排比升华，或段尾替读者总结主题。
- “仿佛在诉说”“似乎在……”等模糊表达堆积。
- 对话后机械补“顿了顿、眼神深邃”，动作却不改变任何东西。
- 连续短句只在制造节奏，句子之间没有新的因果、感官或选择；或用省略号代替动作与反应。
- 情绪只由旁白贴标签或人物自我陈述；刺激出现时便立即说尽，身体、注意、说话方式和后续选择都不再受它影响。
- 对话像交互按钮：一人问、一人给完整信息，两人都没有顾虑自己的利益、关系和现场风险。
- 结构过分整齐，反复出现分派—执行—汇报—验收或固定结尾金句。
- 用抽象警句和象征替代人物对眼前问题的字面回答。

改写不能只换同义词；要改变承载方式，让人物做事、付代价、说具体的话，或删除已由场面演出的结论。

## 7. 交稿前五道门

1. **冷读**：指代、说话人、动作主体、结果和因果无需回看；短句与省略号没有取代正常叙述。
2. **知情**：每条关键信息有入口；所有输出按实际受众复核。
3. **人物**：口吻、关系阶段、能力、权限和反应强度符合档案；承担选择或情绪转折者的身体、注意和行为策略在场内连续变化，对话不是设定问答。
4. **连续性**：时间、方位、场内人员、物品、数量和资源限制闭合。
5. **叙事价值**：本章确实改变了某件事，没有任务流水账、讲义腔、重复边界或为字数存在的场景。

正文若依赖真实资料且读者确需知道，章末最多放三条简短资料注；原创设定不伪造资料注。

### 场内的信息与决定

先有消息到达、亲眼看见或当场提出决定，再有人物据此反应。每一轮对白和判断使用该时刻已经得到的事实、合理猜测和已经形成的决定；猜测仍按猜测写。整章结局与作者侧后台排程不能提前变成人物已知。

### 章节标题

题名应与正文的场面、情绪和变化相称，保留转折意味；作者已确认的题名不因通用偏好擅自重命名。
